# Contributing

This repository is an automatically published artifact feed. Its current
branch intentionally contains no harvester source code, build files,
database migrations, collection configuration, or public aggregation
workflow.

## Reporting subscription problems

Before opening an issue:

1. Re-fetch the subscription; the feed is rewritten on the production
   schedule.
2. Try more than one node. Individual third-party nodes can disappear or be
   blocked by a particular network.
3. Check the `updated` value in `output/status.json`.

Please report an entire subscription that is empty, malformed, or stale.
Use the issue templates and include the affected public file, client name,
timestamp, and a short error message. Do not post credentials or private
connection details.

## Source suggestions

Source suggestions may be submitted through the source-suggestion issue
template. The live source list and ingestion configuration are private
operational data and are not stored in this repository.

## Pull requests

Source-code pull requests are not accepted here. The following files are
generated by the private publisher and will be overwritten:

- `output/**`;
- `README.md` and `README_*.md`;
- `docs/**`;
- `assets/star-history.svg`.

Repository-policy changes require operator review and must still satisfy the
artifact allow-list described in `AGENTS.md`.

## Security

Do not put exploit details or credentials in a public issue. Use GitHub's
private [Report a vulnerability](https://github.com/Au1rxx/free-vpn-subscriptions/security/advisories/new)
form instead.

## Project boundaries

- The project does not operate the third-party nodes in the feed.
- Paid or account-bound sources are not accepted.
- Availability is not guaranteed; see the README disclaimer.
