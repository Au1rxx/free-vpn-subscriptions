ノードの検証方法

公開設定を正規化・重複排除し、公開前にプロキシ経由で実際の HTTP / HTTPS リクエストを送り、端末間の転送を確認します。

検証で分からないこと

小さなリクエストの成功は帯域幅や将来の可用性を保証しません。無料ノードは次の毎時更新までに遅延・停止する場合があります。

どの購読を選ぶ？

自動フォールバックには全体 Clash、出口地域を固定するなら国別、sing-box / v2ray はクライアントに合う形式を選んでください。

❓ よくある質問

本当に無料?

はい。全ノードはサードパーティのボランティアが運営し、自分で公開購読を出しています。当リポジトリはサーバーを持たず、既に公開されているものをテスト・順位付け・再パッケージしているだけです。

データはどれくらい新しい?

外部スケジューラが約 1 時間ごとに公開処理を実行し、データ変更時に検証済みデータベースのエクスポート、購読ファイル、サイトを更新します。

これらのノードは信用できる?

無料ノードは全トラフィックが運営者に見えます。銀行・ログイン・機密情報に絶対使わないでください。公開コンテンツのジオブロック突破には問題ありません。本当のプライバシーには自前 VPS か有料サービスを。

リストにあるのに繋がらないノードがあるのはなぜ?

TCP 到達性と TLS ハンドシェイクは確認していますが、帯域上限、ルーティング異常、証明書期限切れは残ります。いくつか試してください。selector グループにフォールバックがあります。
